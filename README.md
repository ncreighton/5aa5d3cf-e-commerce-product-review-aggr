# E-commerce Product Review Aggregator Bot

Telegram bot for e-commerce sellers that aggregates product reviews from Amazon, Etsy, and Shopify stores into a single digest. Sends daily review summaries, alerts on negative reviews needing response, and tracks average rating trends. Supports multi-store monitoring from one Telegram chat.

## Setup
1. Set `TELEGRAM_BOT_TOKEN` in `.env`
2. `pip install -r requirements.txt`
3. `python main.py`
